## Как работаем вдвоём (и с Claude)

1. **Задача = Issue** с меткой модуля (`module:messaging`, `module:web`…). Взял — назначь на себя.
2. **Ветка** `feature/<модуль>-<кратко>` (латиницей — кириллица в именах веток ломает часть инструментов), PR в `master`, второй человек смотрит хотя бы бегло.
3. **Каждая сессия Claude** начинается с чтения `CLAUDE.md` → `docs/HANDOFF.md` → нужного раздела ARCHITECTURE, а заканчивается обновлением `docs/HANDOFF.md` (что сделано, что дальше, что сломано, какие решения приняты).
4. **Решение, меняющее архитектуру** → новый файл в `docs/decisions/` (ADR). Без ADR — не меняем.
5. **Миграции БД** — только одна ветка за раз меняет схему, иначе конфликт снапшота EF. Договариваемся в чате перед началом.
6. **PR принимаем только с зелёной проверкой** («Проверка» в GitHub Actions: сборка решения, тесты, миграции совпадают с моделью). Красная — сначала чиним в той же ветке.
