## 2026-10-17 — AlDanosAl (сессия Claude) — ветка feature/api-postgres

**Сделано (Issue #18, PLAN 1.1):**
- Ветка переделана под SQL Server по ADR-0009: Npgsql убран, вернулись `UseSqlServer` и старые миграции (`InitialCreate`, `ChangePhoneIdentity`, `AddPhoneAgentToken`, снапшот).
- Новая миграция `20261017150827_CalendarDateColumns`: `Patients.DateOfBirth` и `AutoRuleFires.FiredOnDate` → тип `date`. Проверено у AlDanosAl на LocalDB: старая база обновилась (`dotnet ef database update`), чистая создаётся с нуля.
- Секреты: строка подключения и `Jwt:Secret` только из user-secrets / переменных окружения, в `appsettings.json` их нет, пример — `appsettings.example.json`. Без них вне Development сервер останавливается с понятной ошибкой (проверено).
- Пароля админа по умолчанию нет: `SEED_ADMIN_PASSWORD` / `Seed:AdminPassword`, иначе случайный и один раз в журнал. Касается только пустой базы.
- Время: `UtcDateTimeConverter` для всех `DateTime`, календарные даты — `date` без сдвига пояса.
- Поиск пациентов переносимо: `ToLower().Contains()`.
- `System.Security.Cryptography.Pkcs` явно 10.0.13: `dotnet list package --vulnerable` чисто.
- **Ошибка в Admin исправлена:** запланированное время рассылки уходило по Москве без пояса, сервер считал его UTC, отложенная рассылка уходила на 3 часа позже. Теперь Admin переводит время в UTC.
- README: настройка секретов и первый вход для SQL Server.

**Не доделано / в работе:** PR ждёт ревью Свята. Отложенная рассылка с новым временем вживую (через Admin и телефон) не прогонялась.
**Следующие шаги:** после принятия — Issue #13 (каталог и визиты), затем #15. Разработчикам после слияния: задать user-secrets (README §1.2), иначе сервер не запустится.
**Известные проблемы:**
- Webhook API-ключ сервер пишет в журнал при каждом старте (было и раньше). Стоит писать только при создании.
- Сгенерированный пароль первого админа попадает в `logs/clinichub.log`. Для разработки терпимо, для прода лучше задавать пароль явно.
- Ветка называется `feature/api-postgres`, хотя PostgreSQL в ней больше нет: имя оставлено, чтобы не ломать ссылки в Issue и HANDOFF.
**Решения:** — (по ADR-0009)
